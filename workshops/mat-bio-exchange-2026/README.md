# MAT-BIO Exchange Summer School 2026

Warsaw, 31 August–4 September 2026. [Organizer and programme](https://matbio.natur.cuni.cz/mat-bio-exchange). Original instructor attribution is retained in the materials.

| Session | Topics |
|---|---|
| [Tuesday](tuesday/) | Growth-rate estimation, competition, quasispecies and mutation–selection models |
| [Wednesday](wednesday/) | Logistic growth, predator–prey models, lac operon, FitzHugh–Nagumo, phase-plane analysis |
| [Thursday](thursday/) | Activator–inhibitor models, Turing patterns, wavelength estimates |

R scripts and notebook versions remain together in each day directory. Dependencies include R, deSolve, rootSolve, and Grind; consult the original scripts before installing. Instructor PDFs are preserved in the local archive rather than Git.
