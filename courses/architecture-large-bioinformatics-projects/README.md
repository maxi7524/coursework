# Architecture of Large Projects in Bioinformatics

Summer 2025/2026. Laboratory solutions organized by the [official lab sequence](https://www.mimuw.edu.pl/~lukaskoz/teaching/adp/labs/).

| Laboratory | Work retained |
|---|---|
| [1 — Data formats](assignments/week-01/README.md) | GenPept-to-FASTA converter, submitted usage examples and notebook |
| [2 — CRON and API](assignments/week-02/README.md) | Proteome preparation, batching and ESM structure-prediction requests |
| [3 — Sequence versus structure search](assignments/week-03/README.md) | BLAST, TM-align, Reseek and Foldseek workflow; [PDF report](assignments/week-03/report.pdf), HTML and comparison figures |
| [4–5 — Protein data analysis](assignments/week-04-05/README.md) | PDB/UniProt analysis; [PDF report](assignments/week-04-05/report.pdf), [interactive HTML](assignments/week-04-05/report.html), figures and animations |
| [HPC 1–3 — Protein feature prediction](assignments/hpc-protein-workflows/README.md) | IUPred, ProtBert, Slurm/RAM-disk workflows; [illustrated report](assignments/hpc-protein-workflows/report_refined.md) and submitted result tables |
| [Human genome analysis](assignments/human-genome-analysis/README.md) | Genome statistics, six-frame ORFs and annotation mapping; [report](assignments/human-genome-analysis/genome_analysis_report.md) and compact submitted results |

Final group project: [tAIpipe](https://github.com/NorbertSzala/tAIpipe), with Norbert Szala; maintained in its shared repository. Galaxy and genome-browser exercises are not listed as completed work because no solutions were recovered.

Repository snapshots were compared with five submitted archives. Missing HPC preparation scripts were recovered from the submitted version. Scientific code is preserved; dependency updates and portability fixes are deferred.
