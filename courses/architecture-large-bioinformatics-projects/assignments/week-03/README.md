# Sequence and structure comparison workflow

Original scripts, configuration and notebooks for comparing protein sequences and structures. [Input preparation](DATA.md).

## Original implementation plan

- Coordinate per-structure comparisons through Snakemake.
- Validate input/output directories and run missing processing steps.
- Accept files or recursively traversed directories and preserve dataset grouping.
- Select a method and its supported parameters; initial candidates were BLAST and TM-align.
- Normalize method outputs before producing optional reports.

This is the retained development plan, not a claim that every planned feature is implemented. Reports under `results/` are generated by the workflow.
