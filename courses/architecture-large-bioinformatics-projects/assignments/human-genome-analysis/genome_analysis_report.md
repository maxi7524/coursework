### Analysis
- The human genome assembly has a total length of 3,117,292,070 bp with a global GC content of 40.75%, matching the reference literature data.
- The mitochondrial genome (chrM) has a verified length of 16,569 bp and a GC content of 44.37%.
- The highest regional GC content is located on chr19 (47.66%), which directly correlates with the highest chromosomal concentration of protein-coding genes.

## 2. 6-Frame ORF Finding Performance

Three architectural approaches (BioPython, EMBOSS, and Pure Python) were benchmarked using different genetic code tables for nuclear (`chr1`) and mitochondrial (`chrM`) DNA sequences.

### Method Runtimes for chr1

| Method      |   Runtime (sec) |   ORFs Found |
|:------------|----------------:|-------------:|
| BioPython   |         371.665 |       182870 |
| Pure Python |         224.941 |       182870 |
| EMBOSS      |          10.6   |       168116 |

### Analysis
- BioPython may be slower than Pure Python because of additional W/R operations.
- EMBOSS getorf yields a different number of ORFs because it defines an ORF simply as the region between two STOP codons. Meanwhile, BioPython and Pure Python duplicate these fragments by identifying multiple overlapping ORFs that initiate from different START codons but terminate at the same STOP codon.

### Biological Mechanism of Mapping Discrepancies
- **Nuclear Genome (chr1):** Observed prediction mismatches are caused by the eukaryotic intronic gene structure and alternative splicing mechanisms. Raw 6-frame translation identifies hypothetical continuous open reading frames across genomic DNA, whereas physiological translation utilizes mature mRNA from which introns have been systematically removed.
- **Mitochondrial Genome (chrM):** Mismatches are caused by post-transcriptional modifications. Eukaryotic mitochondrial transcripts are processed from polycistronic RNA units according to the tRNA punctuation model ([Ojala et al., 1981](https://pubmed.ncbi.nlm.nih.gov/7219536/)). Furthermore, functional termination codons (UAA) in several mitochondrial transcripts are not encoded in the genomic DNA sequence but are introduced post-transcriptionally via mRNA polyadenylation ([Anderson et al., 1981](https://pubmed.ncbi.nlm.nih.gov/7219534/)).
