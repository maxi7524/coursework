### k- nearest-neighbours

problem:
- we want to find the closest point from training set 
characterization 
- naive method ~ we use training data as points which predict distances 
    - no cost function to optimize
- to make best prediction we should have evenly distributed points through space 
method type
- supervised - we have data with labels
fitting:
- underfitting - large $k$ (depends on number of points) 
- overfitting - small $k$ (senstivie for small changes)
