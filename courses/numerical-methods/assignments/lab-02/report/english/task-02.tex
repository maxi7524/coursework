\section{Task 2}
We compare algorithms for solving lower-triangular systems.
\textbf{Operation of SolveL}
\begin{enumerate}
    \item loop over index $i$ from $2$ to the length of $x$
    \item loop over indices from 1 to $i$
    \item accumulate products of successive elements
\end{enumerate}
\textbf{Operation of SolveL1}
\begin{enumerate}
    \item loop over row indices
    \item accumulate using matrix multiplication
\end{enumerate}

\noindent
Solving lower-triangular systems is very fast. Attention must be paid to the measured error. It comes from a product of many small numbers, which tends to $0$. When dividing by the reciprocal, we obtain very large errors.
