Model: Turing activator–inhibitor dynamics¶

$$\begin{aligned} \frac{du}{dt} &= \gamma\left(a-u-\frac{\rho vu}{1+u+ku^2}\right),\\ \frac{dv}{dt} &= \gamma\left(\alpha(b-v)-\frac{\rho uv}{1+u+ku^2}\right). \end{aligned}$$

$u$ and $v$ are interacting activator/inhibitor concentrations. The parameters $\gamma$, $a$, $b$, $\rho$, $k$, and $\alpha$ control timescale, inputs, interaction strength, saturation, and relative inhibitor dynamics.

In [ ]:
model <- function(t, state, parms) {
  with(as.list(c(state,parms)), {
    
    du <- gamma*(a-u-rho*v*u/(1.+u+k*u^2))
    dv <- gamma*(alpha*(b-v)-rho*u*v/(1.+u+k*u^2))
    
    return(list(c(du, dv)))  
  }) 
}
