Exercise 1.5 p 26¶

Helpers¶

Beta function is defined as follows: $$ \begin{align} B(x, y) &= \int_0^1 \theta^{x-1}(1-\theta)^{y-1} \mathrm{d}\theta \\ &= \frac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)} \end{align} $$

Part 1 - $X$ distribution¶

Experimentally¶

To find it we just need to plot histogram of our X values, because we randomly select $\theta_i \rightarrow X_i$, by taking histogram of $X$ we make it independent of prior $\theta_i$ value.

Analytically¶

We just go through using beta function property $$ \begin{align*} \mathbb{P}[X] &= \int_0^1 \mathbb{P}[X|\theta]\mathbb{P}[\theta]\mathrm{d}\theta = \int_0^1 \binom{n}{x}\theta^x(1-\theta)^{n-x}\mathrm{d}\theta \\ &= \binom{n}{x} \cdot \frac{x!(n-x)!}{(x + n -x + 1)!} = \binom{n}{x} \cdot \frac{x!(n-x)!}{(n+1)!} \\ &= \frac{1}{n+1} \end{align*} $$ We obtain uniform distribution

Part 2 - Posterior¶

Find experimentally $\theta$ posterior¶

!!! it is overcomplified because we calculate marginal for $X=3$ So we need only take the distribution of $\theta$ We will use elimination method if following setting:

  • we set $f=\mathbb{P}[\theta| X]$
  • we set $g-\mathbb{P}[\theta]$

We obtain $M$ by estimate: $$ \frac{\mathbb{P}[X|\theta]}{\mathbb{P}[X]} \leq \frac{1}{\mathbb{P}[X]} =: M $$

By putting everything in acceptation function we obtain: $$ \frac{f(\theta)}{M\cdot g(\theta)} = \frac{\frac{\mathbb{P}[X|\theta]\cdot \mathbb{P}[\theta]}{\mathbb{P}[X]}}{\frac{1}{\mathbb{P}[X]}\cdot \mathbb{P}[\theta]} = \mathbb{P}[X|\theta] $$ Then we accept our element if: $$ U \leq \mathbb{P}[X|\theta] $$

In lecture function are given $f=p$ and $g=q$

Find a posteriori distribution of $\theta$ parameter¶

To find a posteriori $\theta$ parameter we use Bayes theorem $$ \begin{align*} \mathbb{P}[\theta|X] &= \frac{\mathbb{P}[X|\theta]\mathbb{P}[\theta]}{\mathbb{P}[X]} \varpropto \mathbb{P}[X|\theta]\mathbb{P}[\theta] = \binom{n}{x}\theta^x(1-\theta)^{n-x} \cdot 1 \\ &\varpropto \theta^x(1-\theta)^{n-x} \end{align*} $$ We can conclude that this is kernel of beta distribution: $$ \theta|X \sim \mathrm{\beta}(x+1, n-x + 1) $$ from which be obtain constant, for $X=3, n=9$ we obtain $$ \theta|X \sim \mathrm{\beta}(4, 7) $$

Part 3 - different order¶

We now sample values in reverse order: $$ \mathbb{P}[\theta] = \sum_x \mathbb{P}[\theta|X]\mathbb{P}[X] $$

def cond_dist_rvs(n, param_n_binom=param_n_binom):
    r'''
    Function which return probe from hierarchical model
    
    $$\theta \sim \mathrm{Unif}(0, 1), X \sim \mathrm{Binom}(n, \theta)$$

    It return probe from $\mathrm{Binom}$ 
    '''
    thetas = stats.distributions.uniform().rvs(n) # (n, ) 
    x = np.apply_along_axis(
        lambda x: stats.distributions.binom(param_n_binom, x).rvs(),
        axis=0,
        arr=thetas
    )
    return np.concat((thetas.reshape(-1, 1), x.reshape(-1, 1)), axis=1)  # (n, 2)

    return thetas

Exercise 1.7 p 27 Polyas Urns¶

Part 2 - Martingale check¶

Finite expected value¶

$$ M_n = \frac{\alpha + S_n}{\alpha + \beta + n} \leq \frac{\alpha + n}{\alpha + \beta + n} < 1 $$

Martingale property¶

$$ \begin{align*} \mathbb{E}\left[ M_{n+1} |\mathcal{F_{n}}\right] &= \mathbb{E}\left[ \frac{\alpha + X_{n+1} + S_n}{\alpha + \beta + n+1} | \mathcal{F_n}\right] \\ & = \frac{1}{\alpha+ \beta+ n+1}\mathbb{E}[\alpha+ X_{n+1}+S_{n}|\mathcal{F_{n}}] = \\ & = \frac{1}{\alpha+\beta+n+1}(\alpha+S_{n}+\mathbb{P}[X_{n+1}|\mathcal{F}_{n}]\cdot1) \\ & = \frac{1}{\alpha+\beta+n+1}\left( \alpha+S_{n} + \frac{{\alpha+S_{n}}}{\alpha+\beta+n} \right) =\\ & = \frac{\alpha+S_{n}}{\alpha+\beta+n+1}\left( \frac{{\alpha+\beta+n+1}}{\alpha+\beta+n} \right) = \\ & = \frac{{\alpha+S_{n}}}{\alpha+\beta+n} = M_{n} \end{align*} $$

Divergent¶

We use The Doob martingale convergence theorem

$$ \begin{align*} M_n &= \frac{\alpha + S_n}{\alpha + \beta + n} = \\ &= \frac{\alpha/n+S_n/n}{\alpha/n +\beta/n + 1} \approx \\ &\approx S_n/n \rightarrow X \end{align*} $$

## helper functions
### random sample 
def polya_svm(n, a_param=a_param, b_param=b_param):
    # memory allocation
    X = np.zeros(n, dtype=int)
    S_n = 0

    for i in range(n):
        # probability of obtaining X_n = 0 (from i=0 -> n-1)
        p_i = (a_param + i - S_n) / (a_param + b_param + i)
        # we draw U ~ Unif(0, 1)
        ## case 0: we obtain X_i = 0
        if np.random.random() < p_i:
            X[i] = 0
        ## case 1: we obtain X_i =1
        else:
            S_n += 1
            X[i] = 1

    return X

Exercise 1.18 p 44¶

We assume $\theta \sim \mathrm{Unif}([0, 1])$, than:

Part 1 - $\mathbb{E}[{\tilde{\vartheta}}|\vartheta]$¶

$$ \begin{align} \mathbb{E}[\tilde{{\vartheta}} | {\vartheta}] &= \theta \cdot \mathbb{P}[\tilde{\vartheta}=\theta |\vartheta=\theta] + (1-\theta)\mathbb{P}[\tilde{\vartheta}= 1-\theta|\vartheta=\theta] = \\ &= \theta^{2}+(1-\theta)^{2} = 2\theta^{2}-2\theta+1 = \\ & =2\vartheta^{2}-2\vartheta +1 \end{align} $$

Part 2 - $\mathbb{E}[{\tilde{\vartheta}}]$¶

We use tower rule: $$ \begin{align} \mathbb{E}[\tilde{\vartheta}] &= \mathbb{E}[\mathbb{E}[\tilde{\vartheta}|\vartheta]] = \mathbb{E}[2\vartheta^{2}-2\vartheta +1 ] = 2\mathbb{E}[\vartheta^{2}] -2\mathbb{E}[\vartheta]+1 & \text{for unif: }\\ & = 2 \cdot \frac{1}{3} -2 \frac{1}{2} + 1 \end{align} $$

Part 3 - density function¶

We start from analysis of cdf: $$ F_{\tilde{\vartheta}}(x) = \mathbb{P}[\tilde{\vartheta}\leq x] = \int_{0}^{1}\mathbb{P}[\tilde{\vartheta}\leq x|\vartheta=\theta]p(\theta)\mathrm{d}\theta $$ Because $\mathbb{P}$ is discrete under condition we can write it in terms of characteristics functions: $$ \mathbb{P}[\tilde{\theta}\leq x|\vartheta=\theta] = \mathbb{1}(\theta\leq x)\cdot \theta + \mathbb{1}(1-\theta\leq x)\cdot(1-\theta) $$ We put it into derivative and we obtain (we assume $x \in[0, 1]$): $$ \begin{align} F_{\tilde{\vartheta}}(x) & =\int_{0}^{1 }\mathbb{1}(\theta\leq x)\cdot \theta + \mathbb{1}(1-\theta\leq x)\cdot(1-\theta)\mathrm{d}\theta =\\ &= \int_{0}^{1} \mathbb{1}(\theta\leq x)\cdot \theta p(\theta) \mathrm{d}\theta +\int_{0}^{1}\mathbb{1}(1-\theta\leq x)\cdot(1-\theta)p(\theta) \mathrm{d}\theta = \\ & = \int_{0}^{x} \theta p(\theta) \mathrm{d}\theta+\int_{1-x}^{1}(1-\theta)p(\theta)\mathrm{d}\theta \end{align} $$ Now we differentiate both sites with respect to $x$ variable to obtain density: $$ \begin{align} f_{\tilde{\vartheta}}(x) & =xp(x) - (-1)(x)p(1-x) \\ & = x(p(x) + p(1-x)) & \text{for unif: }p(x)= 1\\ & = 2x \end{align} $$

Part 4 Simulation¶

Methodology¶

To do it for any distribution we proceed as follows:

  1. We choose any distribution (absolute continous)
  2. We choose randomly parameter of seeing bird specie
  3. We choose randomly if we see specie 1 or 2, save results
  4. ...

Name is from that distribution is not changing due to $\theta$ value and it is only based on population size ($x$).

def rvs_for_ISBS(n: int, dist_rvs: callable):
    # select theta parameter at random (prob of class a)
    thetas = dist_rvs(n)
    # select class at random 
    u_values = stats.distributions.uniform().rvs(n)
    class_A = u_values <= thetas
    # we give theta value if class is A, we give (1 - theta) if it is not
    rtn_val = thetas * class_A + (1-thetas) * (1 - class_A) # 
    return rtn_val
